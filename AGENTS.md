# AI Sprint: студенческий репозиторий

Это публичное рабочее место участников курса. Здесь находятся задания, синтетические исходники и инструменты проверки.
Материалы ведущих и данные участников хранятся отдельно и сюда не копируются.

## Работа над заданием

- Общайтесь по-русски. Код и комментарии в коде пишите по-английски.
- Начните с README.md и README.md выбранного упражнения.
- Выполняйте только поручение пользователя. Не решайте остальные задания заранее.
- Для первого упражнения читайте exercises/01-documents/inputs и создавайте exercises/01-documents/answer.md.
- Не меняйте входные документы, их контрольные суммы, проверки и инструкции ради успешного результата.
- Сведения берите из учебных документов. Если ответа нет, обозначьте отсутствие подтверждения.
- В итоговом сообщении перечислите прочитанные файлы, путь результата и выполненные проверки.
- Не утверждайте, что проверка прошла, если её не запускали.
- Используйте только разрешённые данные. Не добавляйте ключи, рабочие документы и данные людей.
- Изменения публикуйте только по поручению пользователя. Результаты первого упражнения остаются локально.

## Разработка учебных инструментов

Python 3.10 или новее, только стандартная библиотека.
Проверки: `python -m unittest discover -s tests -v` и `git diff --check`.
Beads здесь не настроен и для выполнения упражнений не требуется.
