# AI Sprint: студенческий репозиторий

Это публичное рабочее место участника курса. Материалы ведущих и данные людей сюда не добавляются.

## Учебный режим

- Общайтесь по-русски. Код и комментарии в коде пишите по-английски.
- Начните с README.md и README.md выбранного упражнения.
- Выполняйте поручение участника. Не отвечайте за него в проверке знаний.
- Для проверки знаний прочитайте `.claude/skills/study/SKILL.md` и указанный участником материал.
- Используйте только разрешённые исходники. Если сведений нет, обозначьте отсутствие подтверждения.
- Не меняйте учебные материалы во время проверки знаний.
- Сохраняйте отчёты локально в `exercises/01-study/results/`.
- В итоговом сообщении укажите путь результата и фактически выполненные проверки.
- Не утверждайте, что проверка прошла, если её не запускали.
- Изменения публикуйте только по поручению пользователя.

## Сопровождение комплекта

Этот раздел относится к изменению навыка и учебных материалов.
При проведении проверки знаний команды Git и проверки репозитория не нужны.
При сопровождении проверьте локальные ссылки и выполните `git diff --check`.
Beads здесь не настроен.
