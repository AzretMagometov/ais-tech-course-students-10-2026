# Упражнение 1: сформулировать поручение и проверить ответ

Сначала вы формулируете задачу агенту, затем наблюдаете действия и проверяете результат.
[Задание](task.md) адресовано участнику. Прочитайте его самостоятельно.

## Исходники

| Файл | Что внутри |
|---|---|
| [inputs/faq.md](inputs/faq.md) | Учебный FAQ |
| [inputs/policy-contract.md](inputs/policy-contract.md) | Учебный договор |
| [inputs/property-rules.md](inputs/property-rules.md) | Учебные правила |

Все документы синтетические. Веб-сервис для упражнения не требуется.
Файлы `my-prompt.md` и `answer.md` появятся после вашей попытки.

## Порядок работы

1. Прочитайте [ситуацию](task.md) и напишите свой промпт.
2. Откройте корень своей копии в агенте и отправьте написанный текст.
3. Посмотрите в журнале, какие операции он выполнил.
4. Откройте результат и проверьте его по источнику.
5. Сохраните первое поручение и его уточнение для разбора.

Агент выполняет ваше поручение. Он не должен составлять промпт за вас или читать эталон.
Подключение защиты описано в [инструкции доступа](../../docs/agent-access.md).

## После первой попытки

Обсудите результат с ведущим. Сравните свой промпт с вариантом в папке `_reference`, открыв его вручную.
Эта папка недоступна агенту через учебные хуки.
Не вставляйте её содержимое в чат и не прикладывайте файл к запросу.

Для дополнительной технической проверки используйте [описание формата](../../docs/checking.md).
Он нужен проверяющему скрипту и не является обязательным шаблоном первого промпта.
Скрипт не оценивает смысл вывода. Правильную цитату рядом с неверным выводом нужно заметить самостоятельно.

## Ещё две ситуации

После основного задания сформулируйте запрос про размер франшизы.
Проверьте, что агент делает при неоднозначном вопросе.
Затем спросите о механической поломке двигателя личного автомобиля.
Проверьте, как он обозначает отсутствие подтверждения в исходниках.
