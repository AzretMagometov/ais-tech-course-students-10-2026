# Упражнение 1: ответ с проверяемым источником

Нужно поручить агенту одну задачу по трём документам, увидеть действие в журнале и проверить ответ.
Все исходники синтетические. Поднимать веб-сервис для этого упражнения не нужно.

## Что находится в папке

| Файл | Назначение |
|---|---|
| [task.md](task.md) | Полное поручение агенту |
| [inputs/faq.md](inputs/faq.md) | Частые вопросы |
| [inputs/policy-contract.md](inputs/policy-contract.md) | Учебный договор |
| [inputs/property-rules.md](inputs/property-rules.md) | Учебные правила |
| [inputs.sha256.json](inputs.sha256.json) | Контрольные суммы исходников |

Файл `answer.md` создаёт агент. Готового ответа в репозитории нет.

## Выполните

1. Откройте корень своей копии репозитория в агенте.
2. Попросите прочитать `exercises/01-documents/task.md` и выполнить задание.
3. Найдите чтение документа в журнале. Посмотрите, что вернул инструмент.
4. Откройте `exercises/01-documents/answer.md` через список файлов.
5. Откройте указанный документ и раздел. Сверьте ответ по тексту.

Если повторяете упражнение, сохраните предыдущий ответ в локальную папку `attempts`.
Не изменяйте исходники или проверку ради успешного результата.

## Проверьте вручную

- Ответ содержит число, единицы времени, начало отсчёта и существенное условие.
- Цитата перенесена дословно, без исправлений и сокращений.
- Файл источника и заголовок раздела существуют.
- Вывод не противоречит цитате и не теряет её условие.
- В журнале есть выполненная запись, а файл действительно открывается.
- Исходные документы не изменились.

## Запустите автоматическую проверку

Из корня репозитория:

```text
python tools/check_answer.py exercises/01-documents/answer.md
```

В Windows можно использовать `py -3`, в macOS/Linux — `python3`.
Код завершения 0 означает, что технические проверки прошли. Код 1 означает найденную проблему.

Скрипт проверяет четыре непустых раздела, путь и раздел источника, дословность цитаты и неизменность входных документов.
Он не оценивает смысл вывода. Правильная цитата рядом с неверным выводом может пройти эти проверки.

## Что показать в конце

Сообщите: какой инструмент вызван, что он вернул, где сохранён ответ и как он проверен.
Не добавляйте рабочие данные в общий чат.

## Дополнительная попытка

После основной задачи задайте вопрос «Какая франшиза?».
Проверьте, запросит ли агент уточнение вместо произвольного выбора риска.
Затем спросите о механической поломке двигателя личного автомобиля.
Проверьте, отделяет ли агент отсутствие подтверждения от универсального вывода об услуге.
Автоматическая проверка рассчитана на основной вопрос и формат `answer.md` из task.md.
