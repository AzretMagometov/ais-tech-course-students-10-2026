# Study: проверка понимания прочитанного

На показе ведущий отвечает на вопросы по [школьной механике](materials/mechanics.md).
На практике проверьте себя по [тексту первой лекции](materials/lecture-01.md).
Тот же скилл работает с обоими материалами.

## Запустите проверку

Откройте корень студенческой копии в Claude Code. В диалоге агента отправьте:

```text
/study exercises/01-study/materials/lecture-01.md
```

Для повторения показа замените `lecture-01.md` на `mechanics.md`.
Команду `/study` вводят в диалоге агента, а не в PowerShell или терминале.

В другом клиенте или при недоступной команде отправьте:

```text
Прочитай .claude/skills/study/SKILL.md и выполни его инструкции.
Проверь мои знания по exercises/01-study/materials/lecture-01.md.
```

[Скилл study](../../.claude/skills/study/SKILL.md) хранит порядок проверки.
Оболочка, скрипты, Python и Obsidian для упражнения не нужны.

## Ответьте и проверьте отчёт

Агент читает материал, задаёт вопросы по одному и ждёт вашего ответа.
Ответьте своими словами. Эталон и разбор появляются после ответа.
Три основных вопроса проверяют понимание, применение и поиск ошибки.
При пробеле возможен один дополнительный вопрос после объяснения.

Откройте `results/lecture-01-report.md` или путь отчёта, который указал агент.
Найдите свой ответ и сверьте один разбор с разделом материала.
При несогласии покажите основание из текста и попросите пересмотреть оценку.
Три вопроса не подтверждают знание всего материала.

## Порядок практики

| Шаг | Действие |
|---|---|
| 1 | Откройте рабочую папку и запустите study |
| 2 | Ответьте на вопросы |
| 3 | Откройте отчёт и сверьте один разбор |
| 4 | Отправьте сообщение в чат и участвуйте в разборе |

В чат: что пришлось повторить → какой раздел помог → где сохранился отчёт.
Чтобы закончить раньше, напишите: «Заверши после текущего ответа и сохрани частичный итог».
При недоступном агенте работайте в паре. При общем сбое ведущий проведёт ручной разбор по тексту.
Ручной разбор не является запуском скилла.

Отчёты сохраняются локально в `results/`. Не публикуйте ответы участников в общем репозитории.
