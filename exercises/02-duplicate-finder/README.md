# Поиск одинаковых файлов

Поручите агенту создать локальное приложение с интерфейсом. Оно находит одинаковые файлы в выбранной папке.
На лекции ведущий создаёт приложение, проверяет его и добавляет новое требование.
Повторите показ в своей копии или используйте задание для первой самостоятельной попытки.

## Начните с задачи

1. Прочитайте [ситуацию и требования](task.md).
2. Составьте поручение агенту своими словами. Укажите результат, ограничения и способ проверки.
3. Попросите создать приложение в `exercises/02-duplicate-finder/work/` и объяснить запуск на вашей ОС.
4. Запустите приложение и выберите папку `exercises/02-duplicate-finder/samples/`.
5. Пройдите [проверку результата](checks.md).
6. Добавьте требование из второй части задания и повторите проверки.

В `samples/` находятся только входные файлы. Готового приложения здесь нет: его создаёт агент по вашему поручению.
Работайте из корня студенческого репозитория. При необходимости используйте [инструкцию запуска агента](../../docs/start.md).

## Что сохранить

Сохраните свой промпт, приложение, инструкцию запуска и фактические результаты проверок в `work/`.
Для трекинга выберите один вызов инструмента с его ответом и одно затруднение.
Самопроверка по материалу лекции доступна отдельно в [study](../01-study/README.md).
