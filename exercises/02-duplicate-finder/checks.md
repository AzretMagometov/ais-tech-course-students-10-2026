# Проверка поиска дубликатов

Проверяйте работу интерфейса на папке `samples/`. Ожидаемые результаты ниже позволяют принять программу независимо от выбранной реализации.

## Исходные файлы

В папке восемь файлов. Ожидаются две группы и три лишние копии.
Объём лишних копий: **1092 байта**.

| Группа | Пути внутри samples | Размер одного файла | Лишние копии | Объём лишних копий |
|---|---|---|---|---|
| Текст | `documents/meeting.txt`, `archive/meeting-copy.txt`, `archive/ещё одна копия.txt` | 34 байта | 2 | 68 байт |
| Двоичные данные | `data/sample.bin`, `backup/sample-copy.bin` | 1024 байта | 1 | 1024 байта |

`draft/report.txt` и `final/report.txt` имеют одинаковые имена и размер, но разное содержимое. Они не образуют группу.
`unique.txt` тоже не входит ни в одну группу.
Проверьте, что интерфейс показывает путь с кириллицей и пробелами без искажений.

## Измените вход

Скопируйте `samples/` в отдельную папку внутри `work/` средствами файлового менеджера.
Все дальнейшие изменения выполняйте в этой копии.

1. Создайте ещё одну копию `documents/meeting.txt` с другим именем. Ожидаются две группы и **1126 байт** лишних копий.
2. Измените содержимое только добавленного файла. Он должен исчезнуть из группы, итог вернётся к **1092 байта**.
3. Выберите подпапку `draft/`. Ожидается сообщение об отсутствии дубликатов, предыдущие группы должны исчезнуть.
4. Выберите пустую папку. Приложение должно показать пустой результат без ошибки.
5. Вернитесь к исходной `samples/`. Снова ожидаются две группы и **1092 байта**.

## Проверьте новое требование

| Минимальный размер | Группы | Объём лишних копий |
|---|---|---|
| 0 | Текст и двоичные данные | 1092 байта |
| 34 | Текст и двоичные данные | 1092 байта |
| 35 | Только двоичные данные | 1024 байта |
| 1024 | Только двоичные данные | 1024 байта |
| 1025 | Нет | 0 байт |

При нулевом пороге группа двоичных данных должна стоять первой после сортировки по объёму лишних копий.
Отрицательный порог и некорректный ввод должны вызвать понятное сообщение.

## Зафиксируйте результат

Откройте файлы и проверьте один случай вручную. Запишите, какие проверки прошли и что пришлось исправить.
Приложение должно показывать фактическое содержимое выбранной папки, включая изменения из раздела выше.
Исходные файлы после запуска должны остаться неизменными.
