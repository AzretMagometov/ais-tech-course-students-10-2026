# Техническая проверка после первой попытки

Сначала сформулируйте свой промпт и проверьте полученный ответ самостоятельно.
Эта инструкция описывает формат для дополнительной автоматической проверки.
Она не заменяет постановку задачи участником.

Скрипт tools/check_answer.py принимает Markdown-файл с четырьмя непустыми разделами:

- `## Ответ`.
- `## Точная цитата`, где дословный фрагмент оформлен строками через `>`.
- `## Источник`, содержащий строки `Файл: inputs/имя-файла.md` и `Раздел: точный заголовок без ##`.
- `## Проверка и ограничения`.

Если решите выполнить эту проверку, подготовьте отдельную версию результата в таком формате после первой попытки.
Сохраните первоначальный промпт и ответ для сравнения.

Из корня репозитория:

```text
python -I tools/check_answer.py exercises/01-documents/answer.md
```

В Windows можно использовать `py -3 -I`, в macOS/Linux — `python3 -I`.
Параметр `-I` запускает Python в изолированном режиме. Такой запуск разрешён учебным хуком для этого скрипта.

Проверяются структура, существование раздела источника, дословность цитаты и контрольные суммы входов.
Код завершения 0 означает прохождение этих проверок, код 1 указывает на проблему.
Правильность и полноту вывода сверяйте вручную.
Автоматическая проверка не обязательна для первого самостоятельного промпта.
