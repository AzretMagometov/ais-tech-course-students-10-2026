# Получить копию и запустить агента

Для первой попытки достаточно своей копии файлов и работающего Claude Code.
Если Claude Code ещё не установлен, используйте [официальную инструкцию](https://code.claude.com/docs/en/quickstart).
Установка и вход в аккаунт выполняются до лекции.

## Без Git

1. Откройте [учебный репозиторий](https://github.com/AzretMagometov/ais-tech-course-students-10-2026).
2. Нажмите **Code → Download ZIP**.
3. Распакуйте архив в обычную локальную папку, например `C:\Projects`.
4. Откройте распакованную папку. В ней должны лежать `README.md`, `CLAUDE.md`, `.claude/skills/study` и `exercises`.

Для скачивания публичного ZIP аккаунт GitHub и SSH-ключ не нужны.
Работайте с распакованной папкой, а не внутри архива.

## С Git

В PowerShell или терминале выполните:

```text
git clone https://github.com/AzretMagometov/ais-tech-course-students-10-2026.git
cd ais-tech-course-students-10-2026
```

Для чтения публичного репозитория используйте HTTPS. SSH настраивать для упражнения не требуется.
Если хотите сохранять результаты на GitHub, создайте собственную копию кнопкой **Use this template**.
В личную публичную копию не добавляйте рабочие документы и данные людей.

## Windows: открыть в Claude Code

Откройте PowerShell в папке репозитория через Проводник или перейдите в неё командой `cd`.
Если путь содержит пробелы, заключите его в двойные кавычки:

```powershell
cd "C:\Projects\ais-tech-course-students-10-2026"
Get-ChildItem
claude
```

Путь в примере замените своим. Проверьте наличие `README.md` и `CLAUDE.md` в выводе `Get-ChildItem`.
При первом открытии подтвердите доверие только после просмотра файлов.
Самостоятельно прочитайте [задание](../exercises/01-study/README.md).
Запустите study по инструкции ниже. Сначала проверьте доступ к модели.

Перед запуском проверьте доступ к модели. Если клиент запрашивает разрешение, прочитайте конкретное действие перед подтверждением.
Особенности Windows и оболочки описаны в [документации Claude Code](https://code.claude.com/docs/en/setup).

## macOS и Linux

Откройте терминал в корне своей копии и выполните:

```text
claude
```

Прочитайте задание и запустите study по инструкции ниже. Содержание упражнения не зависит от операционной системы.

## Запустить проверку понимания

Прочитайте [материал упражнения](../exercises/01-study/README.md) и выберите файл для проверки.
В Claude Code отправьте:

```text
/study exercises/01-study/materials/lecture-01.md
```

Ведущий использует `mechanics.md`, участники — `lecture-01.md`.
Команду `/study` вводят в диалоге агента, а не в PowerShell.
После обновления файлов откройте новую сессию из корня студенческой копии.
Если команда недоступна, используйте явное чтение инструкции:

```text
Прочитай .claude/skills/study/SKILL.md и выполни его инструкции.
Проверь мои знания по exercises/01-study/materials/lecture-01.md.
```

Этот вариант подходит и для другого клиента с чтением и записью файлов.
Отвечайте на вопросы самостоятельно. Отчёт сохраняется в `exercises/01-study/results/`.

## Если запуск агента не работает

Прочитайте исходники упражнения и составьте поручение в своих заметках.
Зафиксируйте сообщение об ошибке или отсутствующую возможность.
На трекинг принесите попытку и затруднение. Ручной разбор не выдавайте за выполненный запуск агента.
