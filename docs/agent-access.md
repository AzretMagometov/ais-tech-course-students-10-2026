# Доступ агента в первом упражнении

Эталонный промпт находится в `_reference`. Его открывает человек после первой самостоятельной попытки.
Агенту запрещены чтение этой папки и обход через другие инструменты.

## Перед запуском

1. Проверьте, что Python 3.10 или новее запускается в терминале.
2. Просмотрите tools/guard_reference.py и настройки вашего клиента.
3. Перезапустите сессию в корне репозитория после обновления файлов.
4. Откройте `/hooks` и проверьте подключение PreToolUse.
5. В Codex подтвердите доверие новой конфигурации хука. Без доверия клиент пропускает его запуск.
6. Проверьте на отдельной сессии, что попытка прочитать файл из `_reference` блокируется.

Если эталон уже попал в контекст прежней сессии, хук его оттуда не удалит. Начните новую сессию.

## Claude Code

Проектный хук находится в `.claude/settings.json` и вызывает tools/guard_reference.py.
Там же правило Read закрывает `_reference` для файловых вложений через `@`, которые могут обходить вызов Read.
Команда хука — python. Если Python доступен только как python3 или py -3, настройте команду и args вручную.
Не поручайте агенту менять собственную защиту.

## Codex

Настройка находится в `.codex/hooks.json`. Нужна версия с PreToolUse и доверенная проектная конфигурация.
На macOS/Linux пример запускается через python3, на Windows — через python.
Путь к обработчику определяется через корень Git, поэтому этот вариант Codex рассчитан на Git-копию.
Для ZIP-копии используйте Claude Code или задайте абсолютный путь к обработчику в настройке Codex вручную.
Встроенный веб-поиск выключен в `.codex/config.toml`, чтобы не получать эталон из публичного репозитория.
Доверие хуку проверяется через `/hooks`. Новый или изменённый хук не считается автоматически включённым.

## Что разрешено

Хук разрешает чтение открытых учебных материалов, запись результатов и ограниченные команды чтения.
Произвольный Python, команды оболочки со сложными выражениями, сеть и неизвестные инструменты закрыты в этом упражнении.
Это предотвращает обход запрета через скрипт, который читает эталон без явного имени в команде.
Техническую проверку разрешено запускать изолированно: python -I tools/check_answer.py с путём к ответу.

## Границы

Это учебное ограничение поддерживаемых вызовов инструментов, а не изоляция на уровне операционной системы.
Оно работает при исправном Python, загруженной конфигурации и доверенном хуке.
Человек может открыть эталон вручную. Отключённый хук, другая среда или уже скопированный в чат текст не защищаются.

Основания: [хуки Claude Code](https://code.claude.com/docs/en/hooks), [правила чтения](https://code.claude.com/docs/en/permissions) и [хуки Codex](https://learn.chatgpt.com/docs/hooks).
