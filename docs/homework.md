# Задание к первому трекингу

Выполните одну небольшую попытку на своей рабочей задаче.
Выберите действие, результат которого можете проверить сами.
Используйте [карточку задачи](task-card.md) и только разрешённые исходники.
Если своей задачи нет, повторите [поиск одинаковых файлов](../exercises/02-duplicate-finder/README.md).
Для самопроверки знаний используйте [study](../exercises/01-study/README.md).

Принесите:

- Поручение агенту.
- Результат или сообщение об ошибке.
- Один вызов инструмента и возвращённый результат.
- Способ проверки и оставшиеся ограничения.
- Одно затруднение или вопрос для разбора.

Подойдут сравнение инструкций, таблица требований или объяснение фрагмента кода.
Разработка приложения для первой попытки не требуется.
Результаты и рабочие документы храните в своей локальной папке, а не в общем репозитории.
