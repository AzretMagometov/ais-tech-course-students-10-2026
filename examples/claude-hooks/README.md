# Дополнение: проверить ответ при завершении

Этот Stop-хук нужен после первой попытки и перехода к формату из docs/checking.md.
Защита эталона уже настроена отдельно через PreToolUse. Не заменяйте её этим примером.
По умолчанию хук отключён. Он не меняет файлы и не обращается к модели.

## Что происходит

Событие Claude Code `Stop` запускает тот же скрипт, которым проверяют `answer.md` вручную.
Скрипт проверяет структуру, источник, цитату и неизменность входных документов.
При первой ошибке он возвращает замечание модели и просит исправить результат.
Если повторная попытка не прошла, он показывает предупреждение и прекращает автоматические повторы.
Такой результат нужно проверить вручную. Прекращение повторов не означает успешную приёмку.

## Подключение в своей копии

1. Убедитесь, что команда `python --version` запускает Python 3.10 или новее.
2. Просмотрите [пример настроек](settings.example.json).
3. В корне репозитория создайте папку `.claude`.
4. Сохраните содержимое примера в `.claude/settings.local.json`.
5. Запустите Claude Code из корня и проверьте регистрацию через `/hooks`.
6. Проверьте фактическое срабатывание на своей машине.

Если Python запускается как `python3`, замените значение `command` на `python3`.
Если доступен только `py -3`, используйте `command: "py"` и добавьте `"-3"` первым элементом `args`.
Не заменяйте существующие настройки целиком: добавьте блок `hooks` с сохранением остальных параметров.
Не включайте пример в глобальных настройках пользователя.

Чтобы отключить пример, удалите только добавленный Stop-хук из локальных настроек.
Настройки `.claude/settings.local.json` не публикуются в Git.

Пример использует отдельные `command` и `args`, чтобы путь с пробелами передавался одним аргументом.
Проверьте поддержку этих полей в своей версии по [документации Claude Code](https://code.claude.com/docs/en/hooks).
Отдельные тесты обработчика не подтверждают его подключение к клиенту.
