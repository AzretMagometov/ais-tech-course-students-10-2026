# AI Sprint: рабочая папка участника

Здесь вы учитесь формулировать поручения агенту, наблюдать его действия и проверять результат.
Первое упражнение начинается с вашей формулировки задачи.

## Начать

1. Получите свою копию по [инструкции](docs/start.md).
2. Подключите [защиту эталона](docs/agent-access.md) и проверьте, что хук запускается.
3. Самостоятельно прочитайте [задание участнику](exercises/01-documents/task.md).
4. Напишите свой промпт и отправьте его агенту.
5. Проверьте результат по документам и сохраните попытку для разбора.

Файл задания адресован человеку. Не поручайте агенту прочитать его и самостоятельно решить, как выполнять упражнение.
Ситуация и документы заданы, а поручение, контекст, формат и проверку формулируете вы.
Все страховые документы учебные и синтетические.

Агент уже работает в подготовленном окружении: есть системные инструкции, инструкции проекта, документы и инструменты. Даже короткий вопрос использует этот контекст. В обычном чате необходимые сведения и условия придётся предоставить отдельно.

Папка `_reference` предназначена для ручного разбора после первой попытки. Агенту доступ к ней запрещён хуком.
Свои промпты и ответы сохраняйте локально. Публиковать их в общем репозитории для практики не требуется.

## Проверки учебных инструментов

Нужен Python 3.10 или новее. Внешних зависимостей нет.
Из корня репозитория выполните:

```text
python -m unittest discover -s tests -v
```

В Windows можно использовать `py -3`, в macOS/Linux — `python3`.
