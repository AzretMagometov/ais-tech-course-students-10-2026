# AI Sprint: рабочая папка участника

Здесь вы учитесь работать с агентом и проверять понимание прочитанного.
Материалы ведущих и данные людей сюда не добавляются.

## Начать

1. Получите свою копию по [инструкции](docs/start.md).
2. Откройте [упражнение Study](exercises/01-study/README.md).
3. Прочитайте выбранный материал и попросите агента проверить понимание.
4. Ответьте на вопросы и проверьте сохранённый отчёт.

## Материалы

| Материал | Для чего |
|---|---|
| [Получение копии и запуск](docs/start.md) | Windows, macOS/Linux, ZIP и Git |
| [Упражнение Study](exercises/01-study/README.md) | Проверка понимания прочитанного |
| [Школьная механика](exercises/01-study/materials/mechanics.md) | Учебный материал по механике |
| [Первая лекция](exercises/01-study/materials/lecture-01.md) | Материал об устройстве модели и агента |
| [Навык Study](.claude/skills/study/SKILL.md) | Правила проведения проверки |
| [Карточка своей задачи](docs/task-card.md) | Подготовить рабочую задачу |
| [Задание к трекингу](docs/homework.md) | Что принести после первой попытки |

Отчёты сохраняйте локально в `exercises/01-study/results/`.
Публикуйте изменения только по поручению владельца репозитория.
