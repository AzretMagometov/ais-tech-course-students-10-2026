# AI Sprint: рабочая папка участника

Здесь мы учимся поручать агенту небольшие задачи, наблюдать его действия и проверять результат.
Начните с первого упражнения. Код сервиса, платные API и установка библиотек для него не требуются.

## Быстрый старт

1. Получите свою копию репозитория по [инструкции](docs/start.md).
2. Откройте корень копии в Claude Code. Здесь лежат `README.md` и `CLAUDE.md`.
3. Отправьте агенту:

```text
Прочитай exercises/01-documents/task.md и выполни задание.
```

4. Найдите вызов чтения файла и результат операции в журнале агента.
5. Откройте `exercises/01-documents/answer.md` и проверьте его по исходнику.

Порядок работы и критерии приёмки находятся в [упражнении 1](exercises/01-documents/README.md).
Все страховые документы учебные и синтетические. Они не описывают реальные условия страхования.

## Проверки учебных инструментов

Для проверки нужен Python 3.10 или новее. Внешние зависимости отсутствуют.
Из корня репозитория:

```text
python -m unittest discover -s tests -v
```

В Windows вместо `python` можно использовать `py -3`, в macOS/Linux — `python3`.
Проверка ответа описана в [упражнении](exercises/01-documents/README.md).
