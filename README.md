# AI Sprint: рабочая папка участника

Здесь вы учитесь поручать агенту задачи, создавать инструменты и проверять результат.
Материалы ведущих и данные людей сюда не добавляются.

## Начать

1. Получите свою копию по [инструкции](docs/start.md).
2. Откройте [упражнение Study](exercises/01-study/README.md).
3. Прочитайте выбранный материал и попросите агента проверить понимание.
4. Ответьте на вопросы и проверьте сохранённый отчёт.

После study откройте [поиск одинаковых файлов](exercises/02-duplicate-finder/README.md).
Создайте приложение с агентом, проверьте его и добавьте новое требование.

## Вторая лекция: контекст, память и задачи

Откройте [комплект второй лекции](materials/lecture-02/README.md): слайды, текст, памятка команд и образцы документов.
Повторите [четыре практики](exercises/03-context-and-plan/README.md), затем примените приёмы к своей задаче [к трекингу 12 ноября](materials/lecture-02/homework.md).
Для самопроверки используйте study по `materials/lecture-02/lecture.md`, выбирая один из четырёх разделов.

## Третья лекция. Повторяемое → инструмент

В Claude Desktop на вкладке **Code** вы соберёте инструмент для разбора встреч и проверите его в другой папке. Откройте [презентацию](materials/lecture-03/README.md) и [пошаговую практику](exercises/04-meeting-tasks/README.md).
