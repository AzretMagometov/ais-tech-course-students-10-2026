# Первая лекция: «Агент на вашей задаче»

Откройте [презентацию](index.html) в браузере. В ней 23 слайда. Для просмотра не нужны сервер, сборка и интернет. Сохраните всю папку `lecture-01`, чтобы изображения и шрифты открывались вместе со слайдами.

Переходите между слайдами стрелками, пробелом или кнопками внизу. Нажмите «Слайды» для списка, «Экран» для полноэкранного режима. На телефоне также можно листать горизонтальным движением.

После просмотра проверьте себя по [тексту лекции](../../exercises/01-study/materials/lecture-01.md) с помощью [упражнения Study](../../exercises/01-study/README.md).
