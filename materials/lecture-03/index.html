Что такое инструмент

Инструмент — действие, которое клиент выполняет по запросу модели: прочитать файл, запустить команду, найти текст.

1 · МОДЕЛЬ

Просит вызов

Пишет имя инструмента и аргументы. Сама ничего не выполняет.

2 · КЛИЕНТ

Проверяет

Разрешения и хуки: можно ли выполнить без вопроса.

3 · КЛИЕНТ

Выполняет

Читает файл, запускает команду на вашем компьютере.

4 · КОНТЕКСТ

Результат

Вывод попадает в контекст. Модель решает, что дальше.

ЧТО МОДЕЛЬ ЗНАЕТ ОБ ИНСТРУМЕНТЕ

{
  "name": "Read",
  "description": "Reads a file…",
  "input_schema": {"file_path": "string"}
}

Имя, описание и схема входа приходят в контекст в начале сессии. По описанию модель решает, когда вызвать инструмент.

Скрипт как свой инструмент

Агент запускает скрипт через Bash и читает его вывод. Чтобы агент понял результат, у скрипта должен быть контракт.

Контракт скрипта

  • Вход — аргументы и файлы
  • Вывод — понятный текст: что найдено и где
  • Ошибки — в stderr, отдельно от результата
  • Итог — код возврата: 0 — всё в порядке, 1 — найдены проблемы, 2 — не смог запуститься
ПРИМЕР
$ uv run check_protocol.py work/meeting.protocol.md
найдено проблем — 3
- Задача 5: не указан исполнитель
- Задача 6: срок «как будет время» не дата
- Личные данные в протоколе: 8 900 000-12-34
$ echo $?
1

По коду возврата итог понимают агент, хук и любая автоматизация — не читая текст.

uv run запускает Python-скрипт на Windows, macOS и Linux; Python и библиотеки uv ставит сам.

Разрешения

Разрешение — правило, которое клиент проверяет перед вызовом инструмента.

{
  "permissions": {
    "defaultMode": "default",
    "allow": ["Bash(uv run *)", "Read(./docs/**)"],
    "ask":   ["Bash(git push *)"],
    "deny":  ["WebFetch", "WebSearch",
              "Edit(**/*.transcript.md)",
              "Read(./.env)",
              "mcp__meeting-tasks__add_task"],
    "additionalDirectories": ["../shared"],
    "disableBypassPermissionsMode": "disable"
  }
}
defaultMode
режим при старте: default, acceptEdits, plan, auto, dontAsk, bypassPermissions
allow
выполнять без вопроса
ask
всегда спрашивать
deny
отказать; сильнее ask и allow
additionalDirectories
папки вне проекта, к которым есть доступ
disableBypassPermissionsMode
«disable» запрещает включать bypassPermissions; правила allow продолжают работать

Правило: Инструмент(шаблон). Файлы: ~/.claude/settings.json — ваши, .claude/settings.json — проекта, в git, .claude/settings.local.json — ваши в этом проекте.

Как устроен скилл

Скилл — папка с инструкцией SKILL.md. Агент загружает её, когда задача подходит под описание.

meeting-to-tasks/
├── SKILL.md
└── scripts/
    └── check_protocol.py

name: meeting-to-tasks
description: Составляет протокол встречи
  из транскрипта… Используйте, когда
  просят разобрать запись встречи.

СТАРТ СЕССИИ

Описание

В контексте только name и description всех скиллов.

ЗАДАЧА ПОДОШЛА

Инструкция

Агент читает весь SKILL.md.

ПО ХОДУ

Файлы

Читает справочники и запускает скрипты из папки.

Описание решает, вызовется ли скилл. Напишите в нём, что он делает и когда нужен.

Как написать свой скилл

Описание

Шаги

По порядку. Каждый шаг можно проверить.

Чего не делать: не додумывать, не менять исходник.

Скрипт или критерий готовности. Повторять до прохождения.

Размер

SKILL.md короткий. Детали и примеры — в соседних файлах.

Как устроен хук

Хук — команда, которую клиент сам запускает на событии сессии. Модель её не вызывает и не может пропустить.

СОБЫТИЕ

PreToolUse

Агент собрался записать файл.

КОМАНДА

Скрипт

Клиент запускает хук и передаёт JSON события на вход.

КОД ВЫХОДА

0 или 2

0 — продолжить. 2 — заблокировать действие.

АГЕНТ

Причина

Текст из stderr агент видит как объяснение.

"PreToolUse": [{
  "matcher": "Write|Edit",
  "hooks": [{"type": "command",
             "command": "uv run protocol_hooks.py guard"}]
}]

Инструкция, разрешение, хук

МеханизмЧто делаетПример из практики
ИнструкцияПросит. Модель может забыть или понять иначе«Не переносите в протокол телефоны» в SKILL.md

Хуки на практике

Защитить

PreToolUse не даёт записать ключи и пароли в файлы.

Проверить

PostToolUse запускает линтер или сборку после правки.

Довести

Stop не даёт закончить, пока не прошли тесты.

Напомнить

SessionStart загружает состояние задач в новую сессию.

Windows: пишите хуки на Python и запускайте через uv run, не на bash. Права: хук выполняется с вашими правами — чужой хук означает чужую программу на вашей машине.

MCP: внешняя система как инструменты

MCP (Model Context Protocol) — открытый протокол, по которому клиент подключает внешние серверы инструментов.

МОДЕЛЬ

Просит вызов

↔
КЛИЕНТ

Claude Code

↔
MCP-СЕРВЕР

meeting-tasks

↔
СИСТЕМА

Трекер, база, календарь, файл

1 · ПОДКЛЮЧЕНИЕ

Запуск

Клиент запускает сервер как процесс (stdio) или подключается по HTTP.

2 · TOOLS/LIST

Список

Сервер называет свои инструменты: имя, описание, схема входа.

3 · TOOLS/CALL

Вызов

Клиент передаёт вызов модели серверу и возвращает результат.

Готовые серверы и риски

Где брать
