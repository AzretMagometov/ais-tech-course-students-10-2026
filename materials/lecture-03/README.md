# Повторяемое → инструмент

Откройте [презентацию](index.html) в браузере из скачанной папки курса. Оставьте рядом с HTML папку шрифтов, оба файла CSS и файл JavaScript. Переключайте слайды стрелками.

Затем откройте [самостоятельную практику](../../exercises/04-meeting-tasks/README.md). Понадобятся Claude Code, терминал и uv. Все примеры используют вымышленную встречу.
