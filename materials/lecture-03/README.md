# Повторяемое → инструмент

Откройте [презентацию](index.html) в браузере из скачанной папки курса. Оставьте рядом с HTML папку шрифтов, оба файла CSS и файл JavaScript. Переключайте слайды стрелками.

Для практики понадобятся Claude Desktop с доступом к вкладке **Code**, распакованная папка курса и интернет. Вы разберёте вымышленную встречу и проверите результат прямо в приложении. [Перейти к практике](../../exercises/04-meeting-tasks/README.md)
