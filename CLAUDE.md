## Работа в Claude Code

Общие правила, выбор навыка и границы проекта определены в `AGENTS.md`.
Навыки проекта находятся в `.claude/skills/`. Читайте инструкцию выбранного навыка перед его выполнением.

Доступные команды:

- `/study <путь-к-материалу>` — проверить понимание прочитанного.
- `/feature-discovery` — обсудить задачу и собрать требования.
- `/create-prd <путь-к-папке-функции>` — собрать PRD по завершённому обсуждению.
- `/prd-to-beads <путь-к-prd.md>` — подготовить декомпозицию для ревью.
- `/senior-developer` с номером назначенной задачи — реализовать её по спецификации и проверить результат.

Перед началом разработки определите корень проекта участника по `AGENTS.md`.
Команды запускаются из учебной копии, но документы и код приложения записываются в выбранный проект участника.
Передавайте фактические пути результатов между этапами.
Для переноса проверенного `tasks.md` отдельно используйте поручение «создай задачи Beads из этого файла».
Это локальная операция трекера. Она не разрешает коммит или публикацию в Git.

Если команда не обнаружена, прочитайте `.claude/skills/<имя>/SKILL.md` и следуйте инструкции непосредственно.
Используйте файловые инструменты клиента для чтения связанных справочников.
Не запрашивайте личные настройки ведущего для запуска навыков.
